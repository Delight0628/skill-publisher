# Skill Publisher 故障排查指南

## 常见问题及解决方案

### 1. GitHub Token 相关问题

**问题**: 未设置 GITHUB_TOKEN 环境变量

**解决方案**: 访问 https://github.com/settings/tokens 生成新的 Personal Access Token

### 2. Git 相关问题

**问题**: git: command not found

**解决方案**: 下载并安装 Git: https://git-scm.com/downloads

### 3. 仓库已存在

**问题**: Repository already exists

**解决方案**: 使用不同的仓库名称或删除现有仓库

### 4. 网络问题

**问题**: Connection timed out

**解决方案**: 检查网络连接，配置代理
