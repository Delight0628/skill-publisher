# Skill Publisher 工作流详细指南

## 完整工作流程

### 阶段 1: 技能发现与分析

1. 扫描技能目录
2. 解析 SKILL.md 元数据
3. 识别技能类型

### 阶段 2: 项目结构生成

1. 创建临时工作目录
2. 生成标准目录结构
3. 复制源代码文件
4. 生成配置文件
5. 生成 .gitignore

### 阶段 3: 代码质量检查

1. 敏感信息扫描
2. 语法检查
3. 文件结构检查
4. 依赖检查

### 阶段 4: 文档自动生成

1. 生成 README.md
2. 生成 LICENSE
3. 生成 CHANGELOG.md
4. 生成 CONTRIBUTING.md

### 阶段 5: GitHub 仓库创建

1. 验证前置条件
2. 创建仓库
3. 配置仓库设置

### 阶段 6: 版本控制与推送

1. 初始化 Git 仓库
2. 添加远程仓库
3. 提交代码
4. 推送代码

### 阶段 7: 发布确认

1. 验证推送成功
2. 创建 Release 标签（可选）
3. 返回仓库 URL
